RW Codec

RW Codec is a library that provides a cross-platform codec driver for animation and video compression/decompression. RWCodec supports the PS3, Xbox 360, PC (32 and 64-bit), Linux (x86 and ARM), Mac OS/iOS, and Wii.

Requirements

Distribution

LZX support must be removed in the tool binaries before distribution.

LZX can be removed from a build of rwcodec through nant by setting the global property “package.rwcodec.use_lzx=false” like so on the commandline:

nant -D:config=pc-vc-dev-opt tool-build -G:package.rwcodec.use_lzx=false
