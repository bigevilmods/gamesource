Apt uses hash functions generated by the GNU tool "gperf."

The homepage for gperf is: http://www.gnu.org/software/gperf.
Instructions for obtaining the original source code for gperf
are also given on that site.

Since gperf is open source, 3rd-party software, we don't 
distribute it with the Apt package. You, the Apt user,
will probably never need it--UNLESS you want to add support
to Apt for new Flash object members and methods. (Which is
a very, very rare requirement.)

You can download a Windows version of gperf from SourceForge
(www.sourceforge.net). Currently, we use gperf version 2.7.2.

--> However, you can also simply run the script "get_gperf.pl" 
and it will download automatically.

You can run gperf manually, but we don't recommend it because
we provide a script that does everything for you. (run_gperf.pl;
see below.) The input files have the extension ".gperf" and the 
output is either a .h or .cpp file. 

For example, source/Apt/AptObject/sound.gperf is the input file
used to generate source/Apt/AptObject/AptSoundMembers.h.

--> We provide the script "run_gperf.pl" to generate the code for 
you automatically.  The script is slightly complicated because 
the C++ code generated by gperf doesn't compile right away with 
some of the picky compilers we use at EA. So the script takes 
care of patching the output as needed.


The typical usage scenario is:

- You need to add support for some new member or method in
  a Flash object. For example, maybe you want to add a new
  method named "convolve" to Array.

- Run get_gperf.pl to download gperf.exe.

- Run run_gperf.pl on one or more .gperf files. For Array,
  for example, you'd run:

  run_gperf.pl ..\..\source\Apt\AptValue\ArrayMembers.gperf

- Of course, the output file has to be writable (i.e. checked 
  out of your source-control depot). For Array, the output
  file is source/Apt/AptValue/AptArrayMembers.h

- Diff the output file to make sure the generated code looks sensible.

- Rebuild Apt.
