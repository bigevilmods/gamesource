Internally, swfc launches a tool called triangle.exe that takes shapes from a SWF file and tessellates them into triangle-based geometry.

triangle.exe is built from 3rd-party source code. Please make sure you use an appropriate Open Source Deal Sheet if you want to build triangle.exe yourself.

Apt Dev has customized triangle.exe very slightly in order to prevent infinite recursion. If you want to build triangle.exe yourself, do the following:

 * Get the source code.
   It should be located in Apt/version/legal/original_distros.
   If the source code is not located there, it probably means you are not a part of EA.
   If so, please download the source code from here: http://www.cs.cmu.edu/~quake/triangle.html

 * Unzip the code to some folder on your PC. The most important files are triangle.c and triangle.h.

 * Edit triangle.c and insert the following code at the end of the function scoutsegment():


      #if defined(NO_NEW_POINTS_HACK)
      #pragma message("note: no new points hack enabled")
      if (b->verbose > 2) printf("Not correctly inserting new point at intersection (NO_NEW_POINTS_HACK)\n");
      return 1;
      #else
       
      // HERE IS THE OLD CODE
       
      /* Insert a vertex at the intersection. */
      segmentintersection(m, b, &crosstri, &crosssubseg, endpoint2);
      otricopy(crosstri, \*searchtri);
      insertsubseg(m, b, searchtri, newmark);
      /* Insert the remainder of the segment. */
      return scoutsegment(m, b, searchtri, endpoint2, newmark);
       
      #endif

 * Also insert the following code near the end of the function constrainededge():

      #if defined(NO_NEW_POINTS_HACK)
      collision = 0;
      done = 1;
      #else
       
      // HERE IS THE OLD CODE
       
      /* We've collided with a segment between endpoint1 and endpoint2. */
      collision = 1;
      /* Insert a vertex at the intersection. */
      segmentintersection(m, b, &fixuptri, &crosssubseg, endpoint2);
      done = 1;
       
      #endif

 * Open a command prompt.

 * Run setvcvars32.bat from your Visual Studio\VC\bin directory. (This will let you run the MSVC compiler from the command-line.) For example, if you're using Visual Studio 2005, type:

      "C:\Program Files\Microsoft Visual Studio 8\vc\bin\vcvars32.bat"

 * Change to the directory where you edited triangle.c, and compile triangle.exe by typing:

      cl /nologo /Ox -DNO_TIMER -DNO_NEW_POINTS_HACK -DCDT_ONLY triangle.c /link /out:triangle.exe

 * If you did it properly, cl will output "note: no new points hack enabled"

 * You should now see triangle.exe in the same folder.

 * Copy triangle.exe to the folder Apt/version/bin/Apt


Optional: You might also want to change the version string printed in the function info(). It currently looks like this:

      printf("A Two-Dimensional Quality Mesh Generator and Delaunay Triangulator.\n");
      printf("Version 1.6\n\n");
