Batched file loading

When possible, batch read or file load requests together. This allows the files to be loaded in the same order in which they are physically located on the media. On some platforms, this will not matter, but others, such as the PlayStation2s, have slow throughput and seek times. Loading files in the same order they are located on the DVD will reduce seek time and overall load times.

EA Core has a class which reorders a list of files into the optimal order for minimizing the load time of all the files. Refer to the rw::core::filesys::LoadFileList class for more information.
