Configuring and initializing the File library

The file system must be explicitly initialized before it can be used. Use rw::core::filesys::Manager::CreateInstance to create the singleton manager instance. This function takes an rw::core::filesys::Options structure as its sole argument, which gives the application the ability to control various aspects of the file system modules' behaviour. Refer to the documentation for that structure for more information.

To shut down the file library and release its resources, use rw::core::filesys::Manager::DestroyInstance. There should be no pending operations on any devices when the module is shut down.
