Releasing a chunk

When the chunk is no longer needed, it is released using the rw::core::filesys::Stream::ReleaseChunk function. This frees up space in the circular buffer and allows the streamer to continue reading from the file. The streamer will continue reading until it reaches either the end of file or a user-defined end chunk.

Chunks do not need to be released in the same order they were gotten, but the streamer will not restart until the oldest chunk has been released. In other words, it does not fill any holes created by releasing chunks out of order.
