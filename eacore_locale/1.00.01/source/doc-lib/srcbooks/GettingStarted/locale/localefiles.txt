\page p_gettingstarted_locale Working with localized strings

To help deal with localized strings, we provide a class called Locale.  
The idea is that you use a spreadsheet program to define all your 
strings in each language you support.  Then you run that spreadsheet 
file though a tool called Locomoto which produces a data file and 
header file.  You then get strings via the Locale::GetString or 
Locale::WGetString function, using the macros provided in the header 
file generated by Locomoto.

\par Example
See the 'examples' directory under the eacore_locale package root.


*/
