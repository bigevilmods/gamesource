Detailed Description

The Locale class is used to lookup strings by ID number in the compiled locale database.

Parameters:
localefile  pointer to locale data
chtype  CT_ASCII or CT_UNICODE
Creates a Locale object from a locale file.

On big-endian systems, if the locale file is unicode, the constructor will byte-swap all the strings. That means that the localefile memory may be modified by the constructor on big-endian platforms, which means that if the database is stored in read-only memory, an exception will be thrown when the byte swapping is done. The solution to that is to store the database in writeable memory.

The selected language is set to the first one in the database.

const char * EA::Core::Locale::GetString (  int    stringid )  const
 

Parameters:
stringid  ID of string to fetch
return selected string from the specified .loc file (ASCII version)

Returns the string identified by stringID from the specified Locale (.loc) file. Use the stringID specified in the header file created by Locomoto.

This function should be used for strings which are in ASCII format. If your strings are in Unicode format, use the Locale::WGetString function.

If the .loc file was created with an index, stringID can be any valid integer in the range 0 to 65535. If no index was created with the .loc file, stringID will be a zero based array index.

Note that the string is returned as a const. It must NOT be modified.

Note that switching to a new language will make this pointer invalid.

Returns:
A pointer to the requested string. If the cannot be found, NULL is returned.

Locale::Locale, Locale::GetState, Locale::SetLanguage, Locale::WGetString

void EA::Core::Locale::SetLanguage (  int    langId )

set a Locale state

Sets the current Locale state based on the specified Locale (.loc) file. The state must be a valid LocaleState and must be able to be set. The .loc file must be loaded into memory by the client before this function is called.

Currently, the only settable state is LANGUAGEID, so if you try to set any other state, it will be ignored.

Returns:
none
